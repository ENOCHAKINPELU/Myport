# Branded email template

Open `brand-template.html` in your browser to preview the design.

Use `brand-template.txt` for plain-text emails or as the text alternative in an email tool. Keep its message and links consistent with your edited HTML version. The subject line belongs in your email application's subject field.

1. Replace all `[bracketed text]`, including the hidden inbox preview near the start of the file.
2. Remove the optional next-step callout if you do not need it.
3. The button links to your Calendly page for a 30-minute call. To change it, update both the ordinary HTML button and the Outlook VML button (URL and label).
4. Set the subject and sender address in your email application. For example: `Following up on [project name]`.
5. Import the HTML using your email tool's HTML editor and send yourself a preview before using it. Pasting raw HTML into a normal compose window does not render it as a template.

The layout uses tables, inline styles, system fonts, and an Outlook-compatible button. The signature photo uses the public image on your portfolio website so recipients can load it. Some email clients hide images until the recipient allows them; your name and contact details remain readable. The template does not require JavaScript or your website's stylesheet. Its brand colors are navy `#2a2a72`, cyan `#009ffd`, and purple `#7d3cff`. Actual rendering may vary by email client.

This is a personal correspondence template. Nothing is sent or connected to a mailing service by these files.

Browser preview checks passed at desktop (1000px) and mobile (375px) widths without horizontal overflow. These checks do not replace testing in your actual email client; Outlook and Gmail rendering has not been tested.
